# STL Files

This directory contains the two 3D-printable parts and the editable STEP assembly supplied for the robot.

| File | Description |
| --- | --- |
| [`part1.stl`](part1.stl) | Robot mechanical part 1 |
| [`part2.stl`](part2.stl) | Robot mechanical part 2 |
| [`SelfBalancingRobotUsingArduino.step`](SelfBalancingRobotUsingArduino.step) | Editable CAD assembly for the complete robot |

Print orientation, supports, layer height, infill, material, and other slicer settings are not specified because they depend on the printer and the final assembly. Inspect both STL models in your slicer before printing and confirm that their scale is correct.
